# STM32 & Embedded C Practice

Weekly hands-on practice in embedded C and STM32 microcontroller programming on the **STM32 NUCLEO-F446RE** board, using **STM32CubeIDE**.

## 📅 Weeks

| Week | Topics |
|------|--------|
| [Week 1](Week_01/) | Bit manipulation, pointers & memory, circular buffer, STM32 GPIO, timers & interrupts, debugging, GitHub |

Each week's folder has its own README explaining what I learned and how to run the exercises.
